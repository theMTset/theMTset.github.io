# Core Philosophy

I've always been driven by curiosity.

Whether I'm designing software, creating vector graphics, remodeling a bathroom, repairing an HVAC system, or building a deck, I'm motivated by the same question:

**"How does this work?"**

I enjoy taking complex systems apart, understanding how they were built, improving them, and putting them back together better than before.

That mindset shapes everything I create.

I don't see software, design, and engineering as separate disciplines—they're all different expressions of the same process:

* Understand
* Simplify
* Improve
* Build
